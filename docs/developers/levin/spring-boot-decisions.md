# WiseEASE — решения бэкенда

| Решение | Как работает | Где смотреть |
| --- | --- | --- |
| Вход и права | Мария и Никита входят по email и паролю. Сервер хранит хеш пароля и хеш случайного токена сессии. Никита получает историю, правила и заявки назначенного ему счёта. Поле баланса Марии в его снимке равно `null`. | `application/Sessions.java`, `application/Households.java` |
| Миграции и демоданные | Flyway создаёт таблицы `we_*` в выделенной схеме `wiseease`. Hibernate валидирует схему. Повторяемая SQL-миграция загружает демоданные с фиксированным паролем при `WISEEASE_DEMO_ENABLED=true`. Значение флага входит в контрольную сумму, поэтому деморежим можно включить после обычного старта. При уже существующей демосемье миграция пропускает вставку. В прототипе у владельца один помощник, у помощника один подопечный. | `backend/src/main/resources/db/migration/V1__wiseease_schema.sql`, `backend/src/main/resources/db/migration/R__wiseease_demo_seed.sql` |
| Доступ к данным | Spring Data JPA выполняет типовые запросы. Репозитории используют пессимистические блокировки для изменения правил и проведения перевода. Проверка срока после захвата блокировок использует часы БД. | `infrastructure/entity/`, `infrastructure/repository/`, `application/Transfers.java` |
| Причины одобрения | Сумма строго выше порога даёт `ABOVE_THRESHOLD`. Получатель без успешных переводов от Марии даёт `NEW_RECIPIENT`, если включено соответствующее правило. Сервер проверяет причины повторно при создании и сохраняет их с переводом. | `application/Transfers.java` |
| Перевод и баланс | Суммы в EUR хранятся как `BigDecimal` и `numeric`. При `pending` деньги остаются доступны. Обычный перевод или одобрение меняет статус и оба баланса в одной транзакции. При нехватке денег в момент одобрения заявка остаётся в ожидании. | `application/Transfers.java` |
| Повтор отправки | Клиент повторяет `Idempotency-Key` при неизвестном результате. Тот же отправитель, получатель, сумма и ключ возвращают ID существующего перевода. Повтор ключа с другой суммой или получателем возвращает `409`. | `application/Transfers.java`, `backend/src/main/resources/db/migration/V1__wiseease_schema.sql` |
| Срок заявки | 12 часов. В момент истечения сервер прекращает принимать решения и показывает `declined` с `expired: true`. Срок проверяется после захвата блокировки. | `application/Transfers.java`, `application/Households.java` |
| Изменение правил | Выключение проверки новых получателей действует сразу на новые переводы. Причины ранее созданных заявок остаются в истории. | `application/Households.java`, `application/Transfers.java` |
| Синхронизация | `GET /state` читает баланс, историю и настройки из одного снимка PostgreSQL. При интеграции Expo сможет получать этот снимок через polling. | `application/Households.java` |
| Денежный запрос | Сервер принимает запрос только человеку из списка, который настроил Никита. После записи возвращает ID и состояние. Создание запроса не меняет баланс. | `application/Households.java` |

Имена Java-файлов основного кода указаны относительно `backend/src/main/java/com/team/hackathon/features/wiselite/`. Рабочие HTTP-примеры есть в [инструкции запуска](../../../backend/README.md) и [общем API-контракте](../nikita/wise-lite-api.md).
