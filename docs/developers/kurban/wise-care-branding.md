# Переименование бренда в Wise Care

## Согласованный результат

Обновить публичное название продукта на Wise Care: интерфейс, название Expo и PWA, заголовки экранов, тексты приглашений и денежных запросов, документация и демонстрационный лог старого API. Пользователь подтвердил план, координацию общих файлов и сохранение изменения прав `backend/mvnw` при создании ветки.

## Владение и общие файлы

- Владелец задачи: Курбан. Ветка: `codex/kurban-wise-care-branding`.
- Интерфейс: `frontend/app/roles.tsx`, `frontend/app/switch-mode.tsx`, `frontend/app/request.tsx`, `frontend/features/helper/add-person.tsx`.
- Согласованные общие файлы: `frontend/app.config.ts`, `frontend/public/manifest.json`, `frontend/app/_layout.tsx`, `frontend/app/full/_layout.tsx`, `README.md`, `backend/README.md`, `api-prototype/README.md`, `docs/developers/nikita/wise-lite-api.md`.
- В рамках запроса на переименование по всему проекту: текстовые упоминания бренда в `docs/developers/` и описательные комментарии старого SQL-прототипа, сообщение запуска `api-prototype/src/index.ts`.
- Дополнительно обновлены `docs/demo.md` и текст диагностической ошибки в `backend/src/test/java/com/team/hackathon/features/wiselite/WiseEaseApiTest.java`; логика теста не меняется.
- Служебные имена сохраняются: Expo slug/scheme и bundle ID, ключи AsyncStorage, имена пакетов и файлов, ссылки на контракты, схема БД, переменные окружения и демопароль. Это сохраняет совместимость установленных приложений и существующей базы.

## API и шаги

HTTP-контракт: `docs/developers/nikita/wise-lite-api.md`. Методы, тела запросов и ответы не меняются; редактируется только название в описании.

1. Заменить публичные названия и подпись Care в логотипе выбора роли.
2. Обновить документацию без изменения технических ссылок и исторических имён веток.
3. Запустить `npm run check`, проверить остаточные упоминания и `git diff --check`.
4. Проверить экран выбора роли и название PWA/Expo.

## Результаты

Публичное название обновлено в интерфейсе, Expo, PWA, сообщениях, документации, комментариях SQL-прототипа, сообщении старого API и диагностической строке backend-теста. Технические идентификаторы и ссылки сохранены согласно плану.

- `npm run check` прошёл: lint, TypeScript, 8 тестов и web export.
- `./mvnw verify` прошёл после запуска с доступом к Maven-кэшу `.m2` и PostgreSQL. В ограниченном режиме первая попытка остановилась на доступе к файлу блокировки кэша.
- Поиск публичных названий прежнего бренда в исходниках и документации не дал результатов. `git diff --check` прошёл.
- Свежая конфигурация Expo возвращает `name: Wise Care`, существующие slug/scheme сохранены. Экспортированный HTML содержит `<title>Wise Care</title>`.
- В браузере при ширине 390 px проверены подпись Care в логотипе и кнопка `I'm Maria (Care user)`. Скриншот: `/tmp/wise-care-roles.jpg`.
- Уже работающий Metro сохраняет прежний HTML-заголовок до перезапуска Expo. На физическом телефоне проверка не проводилась.
- Повторный fetch подтвердил совпадение базы ветки с `origin/main`. Изменения не закоммичены, merge/push не выполнялись. Пользовательское изменение прав `backend/mvnw` сохранено.
